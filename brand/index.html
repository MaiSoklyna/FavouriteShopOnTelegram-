Brand icon system · v1

The Byme24 knot, on its own.

Three pointed leaves joined by a ring: the gold symbol from the Byme24 logo, rebuilt as clean vector geometry. One 40-unit vesica, radius 26, repeated at 0°, 120° and 240°. Every asset below is built from that single shape, so the brand reads even when the wordmark is gone.

Handoff

Taking it into Figma

  • Drag the files in brand/ onto a Figma canvas. Every shape is a plain path or circle with no masks, so it imports as editable vectors.
  • icons.svg is a sprite. Each <symbol> becomes one component; set frame to 24 × 24 and stroke colour to a variable.
  • Create colour variables Navy, Gold, Dark Gold and a Gold foil gradient style from the palette above.
  • Rebuild the motions with Smart Animate using the values on each card.
